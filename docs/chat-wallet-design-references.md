# 聊天与红包表单设计参考

2026-10-02 在线查看的案例。以下为设计参考，不代表已按案例重做红包表单。

## 1. Send Money — TemiTope Aiyegbusi

[查看案例](https://dribbble.com/shots/24512138-Send-Money)

![Send Money 表单](https://cdn.dribbble.com/userupload/15570878/file/original-7a78025402648727ee9a5b66c9ff07d8.jpg?resize=752x&vertical=center)

适合借鉴红包弹窗：单列等宽表单，余额作为次要信息，金额是主要内容，底部只有一个醒目的主按钮。建议用紧凑分段选择器替代当前三块大型模式卡；收款对象、金额、数量、祝福语和有效期沿同一条左边界排列。红包封面缩成简洁预览，避免挤占输入空间。

## 2. PayRep: Transfer to account — Triumph Anazia

[查看案例](https://dribbble.com/shots/26776521-PayRep-Transfer-to-account)

![PayRep 表单和确认弹窗](https://cdn.dribbble.com/userupload/45716483/file/eef7572c897f5c8fe0777ed08d1dfc78.png?resize=752x&vertical=center)

适合借鉴金额区域和确认信息：减少装饰层次，以浅副色区分输入与说明；可选信息弱化，操作按钮集中在底部。案例中的颜色、账户内容和移动端结构不直接搬入本站。

## 3. Chat — Send money, Send Message — Denis Kovalev / Revolut

[查看动效案例](https://dribbble.com/shots/25740532-Chat-Send-money-Send-Message)

适合借鉴聊天结构：背景连续，消息和金额主次明确，输入与消息自然衔接。本站保留现有主题色和项目列宽，消息区的副色覆盖整块区域；18px 只用于消息内容内距，不作为白色装饰框。不使用凹陷阴影。

推荐组合：用第 1 个案例组织红包表单，用第 3 个案例处理聊天的整体性。大标题、装饰横幅、选项卡、输入区、提示区不再各自堆叠一层卡片。
