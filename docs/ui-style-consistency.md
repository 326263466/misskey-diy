# 页面与卡片样式约定

## 统一结构

- 表单、设置和管理详情页使用 `PageWithHeader contentCard`，标题与正文共享一张 `--MI_THEME-panel` 卡片。
- 列表、时间线保持各条内容自己的卡片；搜索、筛选和说明区域使用 `_panel _panelPadding`，避免表单直接落在页面背景上。
- 页面外层使用 `_pageBody`，宽度由页面列统一决定，不再单独限制正文宽度或增加左右缩进；卡片正文使用 `--MI-cardPadding`（默认 18px）。`contentCard` 内的路由容器不再重复添加 padding。
- 底部操作栏使用 `_pageFooter`，整张卡与正文等宽、内部 18px；聊天会话例外，标题、消息区、半透明输入栏组成连续整卡。
- 弹窗整体使用 panel，标题与正文通过 divider 分隔。全幅媒体、文件列表由自身布局负责；表单使用 `_spacer _spacerCard`，不对所有弹窗子内容强加第二层 padding。
- 分组以标题、间距和细线区分。同一内容区不重复添加灰白相间的大面板。

## 配色与尺寸

| 元素 | 主题变量 |
| --- | --- |
| 卡片、弹窗和底栏 | `--MI_THEME-panel` |
| 标题、正文 | `--MI_THEME-fg` |
| 输入框、未选中的表单选项 | `--MI_THEME-bg` |
| 辅助说明 | `--MI_THEME-fgTransparentWeak` |
| 分隔线 | `--MI_THEME-divider` |
| 选中项 | `--MI_THEME-accentedBg`、`--MI_THEME-accent` |

颜色在现有 CSS Modules 中直接引用主题变量。可复用布局使用共用组件或工具类，不为单独一种颜色额外定义语义不明的类。

响应式网格用 `minmax(min(目标列宽, 100%), 1fr)`；嵌套 flex 表单项允许 `min-width: 0`。弹窗最小宽度不能超过可用容器宽度。不得以隐藏横向溢出来掩盖字段被截断。

## 本轮核对范围

静态索引覆盖 `pages/` 的 258 个 Vue 文件和 `components/` 的 302 个 Vue 文件，再按容器及调用关系核对设置、后台、独立编辑器、搜索/频道/Play、聊天设置、授权和邀请、公共列表与详情。

本轮补齐搜索/筛选卡片、天线编辑和授权页面、聊天设置；统一共享折叠容器及弹窗表面、标题和底栏；移除广告和中继管理的重复横向留白；修正自动分栏及附加信息表单的窄屏溢出。公告的阅读到底判断改为实际滚动尺寸，避免底栏间距变化后无法关闭。

补查删除按钮的主题错误色，以及构建报告的无效样式引用。反应详情的两个同名 CSS Modules 样式块合并，确保头像尺寸和用户行布局在生产构建中生效。

保留明确用途的紧凑分享/状态选择器、图片与视频覆盖层、棋盘和图表语义色、二维码/品牌图标展示色。这些不是裸露的表单内容区，不机械套用另一层卡片。

浏览器验证覆盖共享卡片、输入控件、折叠、18px 内边距、横滑、弹窗、公告和窄屏布局；静态扫描并不等同于逐个登录页面的人工验收。

## 网盘与折叠复查

全局 `--MI-cardPadding` 和 `--MI-pageGap` 统一为 18px，相关回退值同步。卡片正文四边使用同一内边距；提示、统计卡、时钟与功能说明卡也遵循此规则。

网盘正文、日期分组及底栏共用 panel 表面。月份按钮支持鼠标和键盘折叠，折叠保留选择、接收新文件，切换目录重置展开状态；空白处仍接受上传和右键操作。

内容折叠只改变高度，水平位置和宽度保持不变。网盘月份分组禁止文件网格在展开时做位置补间；共享 Folder、FoldableSection、Container 使用纵向网格高度动画。独立页面切换、模态入场及按钮反馈动画不属于内容折叠。

## 全页面追加复查

追加静态索引覆盖当前 `pages/` 的 259 个 Vue 文件，以及 `components/`、`widgets/`、`ui/` 的动画和卡片样式。按路由外壳、共享组件、嵌套调用与媒体查询复核，不将“文件已扫描”视作“所有登录页面已逐一人工操作”。

- 折叠：复核网盘、Folder、FoldableSection、Container、分享二维码与页面编辑器；页面编辑器新增纵向网格高度过渡，折叠保留编辑内容，隐藏时禁止内部控件获取焦点。二维码移除混合淡入动画。代码、详情及只读对象的即时显隐保留，不增加横移或缩放。
- 底色：移除草稿、角色、用户卡、头像设置、关于页、公告及只读预览的动态换底指令。输入框、选择器及进度状态的语义底色保留。福利钱包的透明渐变增加不透明 panel 底层。
- 容器：公开列表、跳转结果与聊天消息详情纳入内容卡；福利页标题说明补卡。正文之间用细线和间距分组。
- 内边距：补齐社区、签到、公告、频道、收藏、图库、Play、公开预览、账号、认证、初始化、聊天、通知、帖子详情与管理统计的正文卡。删除小屏将内容内距改回 8/12/16px 的覆盖。用户活动和单图统计由外层折叠卡独占 18px，去掉重复包装内距。
- 帖子：正文使用 cardPadding，回复连接线随内距移动，头像半径与回复之间的紧凑间隔保持不变。

媒体覆盖层、棋盘、头像周围的定位、图表绘图区、按钮、列表行和安全区属于各自布局，不机械当成正文卡内边距。

## 同列宽度复查

再次索引全部 259 个页面，移除路由正文的 500–1400px 独立宽度以及响应式 12/24/32px 外缩进。删除 universal UI 与 `_pageContent` 针对旧 spacer 的局部覆盖，避免只在一种 UI 或一个嵌套层级生效。

保留项目既有居中宽度：普通桌面布局主体上限 1200px、中列名义宽度 720px；设置等导航布局继续由现有 `_pageLayout` 管理。`_pageBody` 只占满所在列，不把项目改为浏览器全宽。

聊天、探索标签、用户子页、图库、频道搜索、管理表情、反馈、钱包与底部操作栏遵循统一列宽。反馈侧栏与标题在首次显示和滚动时保持顶端对齐。天线编辑器由页面或弹窗分别提供一次内距。独立扩展安装流程保留居中表单宽度；棋盘仅限制棋盘本身尺寸，外层内容卡保持列宽。

浏览器回归测量实际聊天路由及共用 PageWithHeader 的标题、搜索卡和历史卡左右坐标，同时覆盖窄屏、宽屏、亮暗主题、横滑、嵌套卡片和底栏。没有将静态扫描描述为全部页面的人工登录验收。

私信和群聊仅在“聊天”标签采用 `contentCard`。消息区直接使用主题 `panelHighlight` 副色及淡点阵，不额外压暗；背景贴合整列宽度，不添加内阴影或白色内框。外层不加内距，消息内容仅保留左右各 18px，上下不加内距。空消息和开启横滑时也填满可用聊天高度。底部恢复 Git 中的输入区 `_acrylic` 毛玻璃、顶部圆角和 `panel` 工具栏；聊天页脚外层透明，避免不透明底色遮挡毛玻璃。标题、消息和输入区组成连续整卡。“成员、搜索、信息”标签各自使用正常高度的内容卡，不继承聊天的满高背景。

## 子菜单与顶部工具复查

- Folder、FoldableSection、Container 和页面编辑器的分组标题使用 `panelHighlight` 与正文区分，标题使用正常前景色；左右内距统一 18px，包括 Container 的紧凑模式。FormSection/Slot 的普通字段标签不重复添加内距。
- 带内距的表单卡通过共享布局上下文声明所属内容边界。Folder、FoldableSection 和表单链接铺满这张卡，自身保留一次 18px 内距，使无图标标题、前导图标与普通字段同起点，展开后的字段及更深一层的分组也不重复右移。这类横条使用直角，外层卡片保留原有圆角。新的页面边界、独立卡片和表单分栏重置上下文，防止横条伸到其他列；自定义 Folder spacer 的上下文跟随实际响应式内距。
- 表单链接与折叠标题使用一致的横向内距，移除没有图标时的额外文字偏移；群成员卡移除单侧 8px 外距，成员和邀请区放入内容卡。
- “更多”菜单与顶部右侧普通工具图标使用 `fgTransparentWeak`，保留选中、通知和主操作的语义色。“更多”按内容决定高度，最高 560px，同时受可用视口限制；图标格紧凑排列，长标签允许自然增高。
- 删除账号迁移页未使用的全局 `.description` 样式，避免路由加载后给其他同名内容添加额外内距。

浏览器回归覆盖子菜单标题与字段对齐、实际聊天路由的空消息/长消息及标签切换、顶部入口和更多菜单；包含桌面与窄屏、亮暗主题。保持项目原有宽度限制，不将这些验证表述为逐一登录全部页面的人工作业。

## 侧栏路由复查

钱包统一归入 `/settings/wallet`，设置菜单、顶部快捷入口和红包相关链接使用同一路径。钱包正文沿用设置的页头、滚动容器与 18px 内距，不再自行套独立页面或重复内距；钱包菜单选中状态和设置内搜索同步覆盖。兑换、红包及登录要求保持原样。

设置侧栏 16 项、后台侧栏 28 项均匹配所属父路由的子页；用户资料侧栏统一通过 `pathForTab` 生成当前用户的子页地址，社区 4 项归属同一个布局。设置和后台的每一个菜单入口均通过实际侧栏配置与路由容器测试，验证切换时左侧节点保留、右侧内容和选中项更新；同时验证钱包直接打开、窄屏和未登录访问。
