# 游客访问模式

默认使用旧模式。管理员可在“控制面板 → 管理”主动开启新的游客访问模式。旧游客欢迎页面、经典/简洁样式及专用仪表盘均保留。保存设置后刷新游客页面即可检查切换结果。

- **开启游客访问**：游客直接进入公开内容首页，可浏览和搜索全部公开内容，不区分本地与远程。私密内容和需要权限的功能仍受原权限检查保护。
- **关闭游客访问（默认）**：使用原来的登录引导页、展示选项、内容可见范围和搜索角色策略，不额外关闭原先允许的游客浏览或搜索。

开关独立保存为现有 JSON 设置中的 `clientOptions.openGuestAccess`，只有显式 `true` 才启用新模式。新安装和已有站点在未保存该开关时都使用旧模式，不由 `ugcVisibilityForVisitor` 推导开启状态。开放模式运行时采用全部公开范围，关闭后继续使用原来的 `ugcVisibilityForVisitor` 设置。没有增加数据库列，也不改写保存的旧范围。

发布、评论、点赞、收藏、关注等互动继续要求登录。私信、钱包、通知、云盘及管理页面保留原有登录和权限校验；关注者限定、指定用户可见等内容不会因此变成公开内容。

## 后台配置

- **控制面板 → 管理 → 游客访问开关**：只切换访问模式，关闭再开启或重新打开设置页都不会改写原来的内容可见范围。
- **游客内容可见范围**：只在旧模式显示和生效。开放模式无需选择本地或远程，全部公开内容均可访问；原设置保留供切回旧模式使用。
- **控制面板 → 品牌设置**：原有经典/简洁登录引导页样式和相关展示选项继续保留，在关闭游客访问时使用。
- **控制面板 → 角色 → 默认策略**：旧模式沿用原有游客搜索策略。开放模式允许游客搜索范围内的公开内容。公开时间线继续遵循本地/全局时间线权限，登录用户始终遵循原有搜索角色权限。
- **注册**：继续使用后台“开放注册”、邀请码、邮箱验证等既有配置。本次改造不会修改这些设置。关闭开放注册时，注册入口仍进入原有的邀请码流程。

## 验收

使用无痕窗口测试，避免复用登录状态。

| 场景 | 预期 |
| --- | --- |
| 未配置新开关，原内容可见范围为全部、本地或不公开 | 均默认显示原登录引导页 |
| 开启游客访问后打开首页 | 显示公开内容首页，本地与远程公开内容均可浏览 |
| 原游客范围为本地或不公开，再开启新模式 | 公开帖子详情、搜索、用户资料和实时更新可访问，保存的旧范围不被改写 |
| 关闭游客访问后打开首页 | 显示原经典/简洁登录引导页 |
| 关闭游客访问后匿名搜索 | 沿用原有游客搜索策略和内容范围 |
| 开关关闭、开启，再刷新设置页 | 原品牌展示、注册及内容范围配置保持原值 |
| 打开公开帖子、用户主页、频道和允许的搜索 | 正常浏览 |
| 点击发帖、评论、点赞、收藏、关注 | 提示登录；取消后不发送互动请求 |
| 直接打开私信、钱包、云盘或后台地址 | 仍要求登录及相应权限 |
| 请求关注者限定或指定用户内容 | 未授权用户不能读取内容 |
| 关闭开放注册后点击注册 | 继续要求邀请码，不绕过注册规则 |
| 手机端访问 | 可浏览、搜索，并从顶部或菜单进入登录/注册 |

开放模式的游客小组件使用默认的时钟、日历、热门话题，只读展示。不会加载已保存的个人小组件配置。
