# 本地更新信息

更新完成弹窗的「显示更新信息」会展开随前端打包的本地内容，不会跳转到外部发布页。

在项目根目录的 `release-notes.json` 中，使用 `package.json` 的完整 `version` 作为键，值为更新说明字符串数组。每个字符串显示为一条更新信息，支持中文及其他语言内容，按纯文本显示，不解析 HTML。这里的内容是本站维护的发布说明，不经过 Crowdin 翻译。

发布新版本时添加对应条目，再照常构建和部署。版本号必须完全一致（包含 `-alpha` 等后缀）；没有匹配条目的版本会显示本地化的空状态，不会误用其他版本或上游的发布说明。

弹窗标题为“更新完成”，不带站点或源码项目名称。更新内容过长时在内容区域内滚动。自动更新弹窗仍由现有的版本变化检测触发，只修改说明文字而不更改版本号不会重新触发弹窗。
